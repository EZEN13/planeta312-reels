# Звуковой план — mutabar (первые 30,4 с)

Данные для сборки — video/src/releases/mutabar/sound-plan.json, порядок событий совпадает.

## Характер звука
Сухие короткие акценты из одной библиотеки («Звуковая библиотека +VIBE»): хлопки на появлении ключевых слов, один пронос на входе в квартиру, один сигнал «верно» на цене, один тяжёлый удар на финальном «стенку». Голос главный: эффекты приседают под речью. Музыки нет. Не берём длинные хвосты под речь, звук на каждое слово, мультяшные и «денежные» звуки.
Файлы выбраны по замерам (длина, пик, хвост) и стартовому набору README библиотеки — проверить на слух.
